## 🎮 Overview & Story
You find yourself trapped in an eerie corporate building where your ordinary internship takes a dark turn. Navigate through claustrophobic office floors, manage your stamina, interact with the environment, and survive the relentless zombie hordes to escape.

---

## ✨ Key Features
- **Custom First-Person Controller:** Smooth locomotion, camera handling, and a dedicated stamina/sprint system.
- **Zombie AI & Navigation:** Enemy detection, pursuit logic, and attack behaviors.
- **Interactive Environment:** Physics-based Rigidbody push mechanics, door/object interaction system.
- **Survival Mechanics:** Dynamic health management, damage feedback, and responsive UI HUD.
- **Atmospheric Audio Engine:** Centralized `AudioManager` coordinating ambient sounds and event-triggered audio.
- **Complete Game Loop:** Main menu lobby, progressive floor events, game-over screen, and escape sequences.

---

## 🛠 Tech Stack & Architecture
- **Engine:** Unity
- **Language:** C#
- **Physics:** Unity PhysX (Rigidbodies, Custom Colliders)
- **UI:** Unity UI (Canvas, Sliders, EventSystem)
- **Version Control:** Git & GitHub
